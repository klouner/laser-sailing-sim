# Разработка

Сайт статический: HTML, CSS и модули JavaScript. Сборки, зависимостей из npm и транспиляции нет.
Единственная библиотека, three.js r170, лежит в `vendor/`.

## 1. Запуск

```bash
python3 -m http.server 8080      # из корня репозитория
# http://localhost:8080
```

С `localhost` сайт не обращается к серверу статистики и рекордов: `API` в `js/config.js` равен `null`,
рекорды хранятся в браузере. Чтобы проверить работу с сервером на своей машине, добавьте в адрес `?api=1`.
Чтение рекордов при этом всё равно не пройдёт: сервер отвечает только странице с адреса `klouner.github.io`.

## 2. Модули

| Файл | Отвечает за | Зависит от |
|---|---|---|
| `js/main.js` | сцена, свет, камеры, интерфейс, клавиатура и сенсорный слой, игровой цикл, уроки и гонка на экране | все остальные |
| `js/physics.js` | модель лодки. Чистый JavaScript без браузера | нет |

| `js/boat.js` | геометрия лодки, парус, снасти, матрос, качка на волне | three, env |
| `js/scene.js` | небо, берег, облака, вода, компасное кольцо, стрелки, струи ветра, след, брызги, отражение | three, env |
| `js/course.js` | знаки, логика гонки и огибания | three, env, physics |
| `js/lessons.js` | уроки: постановка и проверка цели | physics |
| `js/leaderboard.js` | чтение и запись рекордов | config, analytics |
| `js/analytics.js` | события статистики | config |
| `js/audio.js` | синтез звука на WebAudio | нет |
| `js/hud.js` | схема «вид сверху» на canvas 2D | нет |
| `js/config.js` | адрес сервера, версия физики | нет |

Подробнее о модели лодки и соглашениях о знаках: [PHYSICS.md](PHYSICS.md).

### Как устроена лодка в сцене

```
root            положение и курс
└─ heelG        крен, дифферент на волне, подъём на волне
   ├─ корпус, палуба, шверт, колодец, ремень
   ├─ rig       поворот гика: мачта, гик, парус, карман мачты, шкот
   ├─ rudderPivot   руль, румпель, удлинитель
   └─ sailor    тело одной сеткой и голова
```

Тело матроса строится заново каждый кадр: `makeBody` в `js/boat.js` расставляет кольца одной сетки
по суставам, которые выдаёт кинематика. Число вершин постоянно.

### Вода и то, что на ней лежит

Высоту волны считает одна формула в двух местах: `env.heightAt(x, z)` в JavaScript и `waveHG` в шейдере.
Любой материал можно положить на воду функцией `floatOnWaves(material, env, lift)`. Материалы корпуса и шверта
обёрнуты в `sinkInWater`: подводная часть уходит в цвет толщи.

Если меняете формулу волны, меняйте её в обоих местах, иначе лодка поплывёт над водой или под ней.

## 3. Игровой цикл

`frame()` в `js/main.js` вызывается на каждый кадр:

1. `adaptQuality(dt)` следит за частотой кадров.
2. `simulate(dt)`: клавиатура, автопилот, `env.update`, шаги физики по 1/120 с, проверка урока или гонки,
   обновление лодки, воды, следа, брызг.
3. Стрелки векторов, сенсорный слой, камера, интерфейс.
4. Схема сверху, не чаще 20 раз в секунду.
5. Отражение лодки на высоком качестве, затем основной кадр.

`simulate` ничего не рисует. Это позволяет проматывать время в проверках: `window.__sim.warp(секунды)`.

Текст в интерфейсе обновляется через `setText(id, text)`: она пишет в DOM, только если текст изменился.
Раскладка пересчитывается не каждый кадр, а по флагу `layoutDirty`.

## 4. Выпуск новой версии

1. Проверьте изменения: раздел [Проверки](#5-проверки).
2. Поднимите номер версии. Он стоит в `index.html` в тринадцати местах: у стилей, у главного модуля
   и у каждого модуля в карте импорта. Меняется одной командой:

   ```bash
   sed -i 's/?v=57/?v=58/g' index.html
   ```

3. Закоммитьте и запушьте в `main`.
4. Дождитесь зелёного запуска «Deploy to GitHub Pages» в GitHub Actions. Обычно это полминуты, иногда до пяти минут.
5. Откройте сайт и посмотрите номер версии внизу панели настроек.

**Зачем номер версии.** GitHub Pages разрешает браузеру хранить файлы 10 минут. Без номера браузер может взять
часть модулей новыми, а часть старыми из кэша, и сайт сломается или будет работать по-старому. Карта импорта
в `index.html` приписывает номер каждому модулю, поэтому новая версия загружается целиком.

**Новый модуль** нужно добавить в карту импорта в `index.html`. Иначе он будет загружаться без номера версии.

Посетитель, открывший сайт в первые 10 минут после выкладки, может увидеть прежнюю версию. Лечится обновлением страницы.

## 5. Проверки

### Физика

```bash
node tools/simtest.mjs
```

Печатает установившиеся режимы на разных курсах и ветрах, угол лучшей лавировки, поведение без рулевого,
разгон, выход из левентика, оверштаг с разным рулём, поворот фордевинд, гонку автопилотом.
Автоматических порогов нет: вывод сравнивают глазами с таблицами в [PHYSICS.md](PHYSICS.md).

### Синтаксис

Файлы написаны как модули ES. Node проверяет их только с расширением `.mjs`:

```bash
for f in js/*.js; do cp "$f" /tmp/check.mjs && node --check /tmp/check.mjs || echo "ошибка в $f"; done
```

### Браузер

Автоматических тестов в репозитории нет. Перед выпуском стоит пройти руками:

- страница открывается без ошибок в консоли;
- урок 1 запускается, подсказка под заданием меняется;
- гонка: огибание буя засчитывается, финиш в воротах показывает время;
- на узком экране 320 пикселей текст в шапке и плашке урока не обрезан;
- вид из кокпита и переключение качества графики.

Проверки удобно автоматизировать через Playwright и `window.__sim`. Запросы к `sh38.ru` в таких проверках
нужно либо глушить, либо помечать: иначе в статистику попадут тестовые сеансы.

## 6. Отладка в браузере

В консоли доступен объект `window.__sim`:

| Поле | Что это |
|---|---|
| `state`, `ctl` | состояние лодки и управление, можно менять на лету |
| `warp(sec)` | промотать время |
| `startLesson(i)`, `startRace()` | запустить урок по номеру с нуля или гонку |
| `lessons`, `course` | ход урока и гонки |
| `setCamera(mode)` | `chase`, `top`, `side`, `cockpit`, `free` |
| `camera`, `controls`, `renderer`, `scene` | объекты three.js |
| `boat`, `env`, `audio`, `stats` | лодка, среда, звук, статистика |
| `boat.pose` | поза матроса. `boat.holdPose = true` замораживает её |
| `level`, `dpr`, `prefs` | уровень качества, плотность пикселей, настройки вида |

Примеры:

```js
__sim.ctl.windSpeed = 18; __sim.state.heading = 170; __sim.warp(10)   // фордевинд в свежий ветер
__sim.startLesson(9)                                                  // урок «Старт по сигналу»
__sim.stats.track('ping', {})                                         // отправить событие статистики
```

Параметры в адресе:

| Параметр | Что делает |
|---|---|
| `?debug=1` | шлёт пробное событие статистики и показывает ответ сервера на экране |
| `?api=1` | включает сервер при запуске с `localhost` |

## 7. Что хранится в браузере

Ключи `localStorage`:

| Ключ | Что |
|---|---|
| `laser3d.view` | качество графики, счётчик кадров, звук |
| `laser3d.passed` | пройденные уроки |
| `laser3d.vid` | случайный номер посетителя для статистики |
| `laser3d.name` | имя, вписанное в рекорды в прошлый раз |
| `laser3d.leaderboard.v3` | рекорды, если сервер недоступен. Цифра в конце это версия физики |

Cookies не используются.

## 8. Частые задачи

### Добавить урок

В `js/lessons.js` добавьте объект в массив `LESSONS`:

```js
{
  id: 'myLesson', group: 'Мастерство', title: 'Название',
  goal: 'Текст задания.',
  usesCourse: 'W',                      // необязательно: показать знаки
  setup(state, ctl) { /* поставить лодку и ветер */ },
  check(out, state, el, mem, course, ctl) {
    // el — секунд с начала урока; mem — память урока между вызовами
    return { progress: 0.5, note: 'Подсказка', done: false };   // или { fail: 'Почему провал' }
  },
  teardown(ctl) { /* вернуть то, что меняли в ctl */ },
}
```

`settleRig` после `setup` вызывается автоматически. Если урок меняет `ctl.lockHeading`, `ctl.autoTrim`
или `ctl.windSpeed`, верните их в `teardown`.

Проверьте, что урок проходится: в консоли можно управлять лодкой скриптом через `__sim.ctl` и `__sim.warp`.
Обновите таблицу уроков в [GUIDE.md](GUIDE.md).

### Изменить физику

Порядок описан в конце [PHYSICS.md](PHYSICS.md). Главное: если изменилась скорость лодки, поднимите версию
физики в двух местах, `API.ver` в `js/config.js` и `KEY` в `js/leaderboard.js`.

### Сменить адрес сервера

`API.base` в `js/config.js`. Сервер должен разрешать запросы со страницы `https://klouner.github.io`.
Контракт: [server/README.md](../server/README.md).

### Отключить статистику и общий рекорд

В `js/config.js` поставьте `export const API = null;`. Рекорды останутся в браузере каждого посетителя.

### Добавить событие статистики

В `js/main.js`: `stats.track('тип', { поля })`. Сервер принимает любые типы и поля. Чтобы событие появилось
в админке отдельным разделом, его нужно описать серверной стороне.

## 9. Производительность

- **Уровни качества** `LEVELS` в `js/main.js`: плотность пикселей, размер карты теней, набор эффектов `fx`.
  `fx` 0 без эффектов, 1 брызги и пена, 2 ещё и отражение лодки.
- **Автоподстройка** `adaptQuality`: раз в секунду считает среднюю частоту кадров. Ниже 42 кадров две секунды
  подряд снижает плотность пикселей на 0,25. Если она уже минимальная, в режиме авто снижает уровень качества.
  Выше 56 кадров восемь секунд подряд поднимает плотность обратно.
- **Неподвижные детали** лодки склеены в одну сетку на материал функцией `mergeStatic`. Деталь, которая должна
  двигаться, помечается `userData.keep = true`.
- **Канаты** имеют постоянное число вершин и обновляются на месте: `rope(parent, mat, r, nPts)`.
- **Временные векторы** берутся из пула `tv()`, чтобы не создавать мусор каждый кадр.
- **Сетка воды** густая у лодки и редкая вдали.

Скорость на реальных телефонах измеряется только счётчиком кадров на самом устройстве и статистикой:
события `ping` несут частоту кадров и уровень качества.

## 10. Вёрстка и стиль

Стиль повторяет сайт школы silavetra.com: фон `#121212`, чёрные блоки, скругление 4 пикселя, прописные подписи,
акцентные цвета синий `#0047ff` и оранжевый `#ff5700`. Шрифт Inter. Иконки нарисованы линиями в SVG,
эмодзи в интерфейсе нет.

Точки перелома в `style.css`:

| Условие | Что меняется |
|---|---|
| ширина до 900 пикселей или сенсорный экран до 1200 | телефонная раскладка: сенсорный слой, панель шторкой снизу |
| ширина до 360 | ещё компактнее, подпись у кнопки поворота скрыта |
| ширина до 900 и высота до 700 | схема «вид сверху» скрыта |

Подписи в 3D-сцене держат размер в пикселях экрана: `makeTextSprite` и `setLabelScale` в `js/scene.js`.

После правок интерфейса проверяйте ширину 320, 390 и 412 пикселей: текст в шапке, в плашке урока
и на кнопках не должен обрезаться.

## 11. Грабли

- **Порядок объявлений в `main.js`.** Файл выполняется сверху вниз. Обращение к `let` или `const`,
  объявленным ниже, из кода, который выполняется сразу, роняет всю страницу. Функциям, которые вызываются
  позже, это не мешает.
- **`settleRig` после перестановки лодки.** Иначе гик окажется на наветренном борту и лодку дёрнет.
- **Знаки.** Крен положителен на левый борт, гик положителен на правом. Таблица в [PHYSICS.md](PHYSICS.md).
- **Один модуль, один адрес.** Импортируйте модули только как `./имя.js`. Если один и тот же файл импортировать
  по двум разным адресам, браузер загрузит его дважды, и у статистики появятся два разных сеанса.
- **Звук до первого касания.** Браузер не даст запустить звук без действия пользователя. `audio.start()`
  вызывается из обработчика нажатия.
- **Вид из кокпита.** Положение камеры сглаживается в системе корпуса лодки, а не в мире. Иначе камера
  отстаёт от лодки на переменную величину, и всё вблизи дрожит.
- **Тестовые запуски и статистика.** Страница, открытая с адреса `klouner.github.io`, пишет в настоящую базу.
