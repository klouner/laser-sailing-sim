# Проверки второй версии

Здесь лежит всё, чем версия 2 проверялась при разработке. Запускать после любой правки физики, уроков, гонки или отрисовки.

## Физика без браузера: `phys/`

Нужен только Node.js. Запуск из папки `v2/tools/phys`.

| Скрипт | Что проверяет | Что должно быть |
|---|---|---|
| `p150.mjs` | полные курсы 135–165° при 16–24 узлах | везде `ok`, без переворотов |
| `run.mjs` | курс прямо по ветру, с порывами и без | `sideFlips 0`, `crewCross 0`: матрос не пересаживается |
| `gy.mjs` | ложные сообщения «Гик перелетел» в 24 ситуациях | ни одного сообщения |
| `rt.mjs` | оверштаг с перекатом и без при 5, 8, 12, 18 узлах | с перекатом пройдено против ветра не меньше, без переворотов |
| `tk.mjs` | длительность оверштага с плавной перекладкой руля | 3–4 с при 8–18 узлах |
| `lee.mjs` | ход «за ветер» и подъём после переворота | до ~25° гик не перелетает; лодка встаёт |

Поляра пересобирается после любой правки физики: `node v2/tools/polar.mjs > v2/js/polar.js`.

## В браузере: `checks/`

Один раз: `cd v2/tools/checks && npm install && npx playwright install chromium`.
Перед запуском поднять сайт из корня репозитория: `python3 -m http.server 8765`.

| Скрипт | Что делает |
|---|---|
| `checkall.js` | полный обход: 14 уроков, камеры, небо, качество, галки, ползунки, кнопки, переворот, соперники, два телефона |
| `race3.js` | гонка от первого сигнала до финиша и три урока до конца |
| `livecheck.js` | живой сайт: обе версии открываются без ошибок |
| `textaudit2.js`, `hintfit.js` | текст не обрезается на телефонах 320–412 точек |
| `v2shot.js` | снимок сцены: `node v2shot.js "?nointro" имя "js до снимка" ожидание_мс ШxВ` |
| `seq2.js` | раскадровка оверштага через полсекунды |
| `anchor.js` | вода стоит на месте: сдвиг узора при перестановке лодки на метр |
| `sharp.js` | чёткость на плотном экране телефона |
| `fps2.js` | частота кадров обеих версий |

Снимки складываются в `checks/out/`.

Переменные окружения:

- `SOFT_GL=0` — рисовать настоящей видеокартой. Без неё скрипты включают программную отрисовку: так они работали в облаке, где видеокарты нет.
- `BASE` — адрес версии 2, по умолчанию `http://localhost:8765/v2/`.

Скрипты блокируют запросы к серверу статистики `sh38.ru`, чтобы проверки не выглядели в админке как посетители. Исключение — если нужно проверить саму статистику: тогда заход помечается `utm_source=selftest`.
