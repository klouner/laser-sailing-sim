# Лазер 3D

Интерактивный 3D-тренажёр по управлению швертботом класса **Laser (ILCA 7)** для парусной школы «Сила ветра».
Ветер, парус, руль, шверт и матрос считаются физической моделью, поэтому приёмы работают так же, как на воде:
лодку можно увести из левентика задним ходом, потерять ход на резком руле, перевернуть на фордевинде.

**Сайт:** https://klouner.github.io/laser-sailing-sim/

Работает в браузере на компьютере и телефоне. Сборки нет: это статические файлы и three.js.

## Что умеет

- **Физика.** Лодка считается как твёрдое тело с четырьмя степенями свободы: ход, дрейф, рыскание и крен.
  Парус, шверт и руль работают как крылья со срывом потока. Гик живёт своей динамикой и ограничен шкотом.
  Матрос служит подвижным балластом. Волна толкает лодку по склону. Подробности в [docs/PHYSICS.md](docs/PHYSICS.md).
- **Одиннадцать уроков** в двух блоках: от выхода из левентика до старта по сигналу и штрафного оборота 720°.
- **Гонка на время** с двумя знаками и общей таблицей десяти лучших результатов.
- **Настройки паруса:** оттяжка гика, каннингхэм, оттяжка шкотового угла. Меняют форму паруса и поведение лодки.
- **Матрос** сидит там, где его держит физика: откренивает, пригибается под гиком, переходит на другой борт
  и перехватывает руки после поворота.
- **Картинка.** Небо с дымкой, вода с рябью, пеной и брызгами, отражение лодки, дальний берег, порывы видны
  на воде тёмными пятнами.
- **Звук** синтезируется на лету, без файлов: ветер, вода, полоскание паруса, удар гика.
- **Пять камер**, в том числе вид из глаз матроса.
- **Подсказки** в реальном времени: курс относительно ветра, состояние паруса, что делать.
- **Телефон.** Отдельный сенсорный слой управления, ветер можно привязать к компасу телефона.

## Управление с клавиатуры

| Клавиша | Действие |
|---|---|
| `A` / `D` или `←` / `→` | руль влево и вправо |
| `W` / `S` или `↑` / `↓` | подобрать и потравить шкот |
| `Space` | пауза |
| `R` | сброс |
| `C` | следующая камера |
| `T` | поворот автоматом: оверштаг, на попутных курсах фордевинд |
| `V` | показать или скрыть стрелки векторов |

Полное описание интерфейса в [docs/GUIDE.md](docs/GUIDE.md).

## Запуск на своей машине

Нужен любой HTTP-сервер: модули JavaScript не загружаются с `file://`.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

При запуске с `localhost` сайт не обращается к серверу статистики, рекорды хранятся в браузере.

Проверка физики без браузера:

```bash
node tools/simtest.mjs
```

## Публикация

Каждый пуш в ветку `main` запускает `.github/workflows/pages.yml`, который выкладывает содержимое репозитория
на GitHub Pages. Перед пушем нужно поднять номер версии в `index.html`: порядок описан
в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Статистика

Сайт отправляет на сервер школы техническую статистику посещений: устройство, время на сайте, пройденные уроки.
IP-адрес записывает сервер. Cookies не используются. Что именно собирается, описано в [server/README.md](server/README.md).
